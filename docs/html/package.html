Spid3r Package System (spkg)

Create, install, vendor, audit, run CLI tools from, and publish Spid3r packages with content-addressed SHA-256 locking, zero install scripts, and optional Ed25519 signature verification.

01Architecture Overview: How It Works

Deterministic resolution, global caching, isolated vendoring, and compiler-enforced lockfile verification.

Resolution & Vendoring Pipeline

  1. 1
    Reads spider.toml (single crate or [workspace]) including optional --dev / --extra dependency groups.
  2. 2
    Unifies SemVer ranges across transitive dependencies while skipping releases marked in signed yanked.txt.
  3. 3
    Fetches archives or target binary wheels (package-<target>.tar) into the shared global cache (paths.cache_dir / SPID3R_CACHE_DIR).
  4. 4
    Verifies Ed25519 signatures and hashes before unpacking sources, .spid3r-manifest.toml, and _native/<target>/ into vendor/<pkg>/.
  5. 5
    Writes pinned source digests, manifest-sha256, native-sha256, ffi-libs, and used_by back to spider.lock.

Automatic Vendor Imports

The Spid3r compiler and runtime search vendor/ automatically relative to the project root. When nettools or mathlib is vendored, import its module name directly:

src/main.matrix
spid3r 
import "nettools/lib" as nt;

fn main() {
    let info = nt.subnet_calc("192.168.1.0/24");
    println("nettools v" + nt.VERSION + " -> " + string(info));
}

Inspect module resolution across stdlib, your project, and vendor/ with spkg modules src/main.matrix --tree.

Default Public Registry: packages.registry defaults to https://spid3r-spkg.github.io. Override it via SPID3R_REGISTRY or spid3r.ini, set SPID3R_REGISTRY=none in air-gapped networks, or bypass registries entirely with --path and --git.

0260-Second Quickstart

Start a project, install libraries, run your app across engines, or install global CLI tools.

Project Workflow (Libraries)

terminal — pip-style or explicit init
bash 
# 1. Quickest workflow in an empty folder:
mkdir hello_demo && cd hello_demo
spkg install hello          # creates spider.toml + installs latest
spkg search                 # browse catalog.txt + vendor/

# 2. Or initialize an explicit project scaffold:
spkg init my_app && cd my_app
spkg install hello==0.1.0
spkg tree
spkg verify
spkg uninstall hello
spkg dist                   # emits target/my_app.matrixc

Global CLI Tool Workflow ([bin])

terminal — spkg tool
bash 
# Install CLI binaries from registry, --path, or --offline cache
spkg tool install nettools
spkg tool list

# Run directly from any terminal (Windows / Linux / macOS)
nettools subnet 10.0.0.0/24 --json
spkg tool uninstall nettools

Launcher shims live in %LOCALAPPDATA%\Spid3r\state\bin (Windows) or ${XDG_STATE_HOME:-$HOME/.local/state}/spid3r/bin (Linux/macOS), added to PATH by both installers.

03Developing & Writing a New Package

Author reusable libraries and CLI binaries with clean public exports.

Recommended Library Layout

package directory
tree 
slugify/
├── spider.toml
├── src/
│   ├── lib.matrix       # public library API
│   └── helpers.matrix   # internal module helpers
└── tests/
    └── basic_test.matrix

For library crates, set entry = "src/lib.matrix" in spider.toml so consumers, spkg pack, and spkg dist know the library entry module.

Exporting Symbols with public

slugify/src/lib.matrix
spid3r 
// slugify/src/lib.matrix
public const VERSION: string = "0.1.0";

public fn slugify(text: string) -> string {
    return text.trim().to_lower().replace(" ", "-");
}

Linking Locally During Development

terminal — local path dep
bash 
spkg init demo_app && cd demo_app
spkg add slugify --path ../slugify
spid3r test

Consuming the Package

demo_app/src/main.matrix
spid3r 
import "slugify/lib" as slug;

fn main() {
    println(slug.slugify("Hello Spid3r Package"));
    println("version = " + slug.VERSION);
}
Import Path Mapping Rule: Everything inside a package's src/ folder is unpacked directly under vendor/<pkg>/. Thus slugify/src/lib.matrix becomes vendor/slugify/lib.matrix (imported as import "slugify/lib"), and src/net/client.matrix is imported as import "pkg/net/client".

04Manifest (spider.toml) & Lockfile (spider.lock)

Complete schema for metadata, native [ffi], CLI [bin] tools, dependency constraints, and reproducible locks.

Full spider.toml Example

spider.toml
toml 
[package]
name = "winplot"
version = "0.2.0"
entry = "src/lib.matrix"
description = "Data plotting & Windows GUI charting"
license = "MIT"
spid3r = ">=1.1.0"
categories = ["data-science", "gui"]
targets = ["windows-x86_64", "linux-x86_64", "any"]

[ffi]
# Verified & auto-linked by yamc / spid3r build
libs = ["user32", "gdi32"]
bundled = ["lib/winplot_core.lib"]
runtime_libs = ["bin/winplot.dll"]

[bin]
winplot-cli = "src/cli.matrix"

[dependencies]
slugify = "../slugify"
local_lib = { path = "../libs/local_lib" }
router = { git = "https://github.com/org/router.git", rev = "v1.2.0" }
json_fmt = { version = ">=1.0.0, <2.0.0" }
internal_auth = { version = "=2.0.1", registry = "corp" }

[dev-dependencies]
test_helpers = { version = "^0.4.0" }

[optional-dependencies.gpu]
cuda_accel = { version = "^0.2.0" }

Generated spider.lock Format

spider.lock
toml 
[[package]]
name = "winplot"
version = "0.2.0"
source = "registry+^0.2.0"
sha256 = "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
manifest-sha256 = "7d865e959b2466918c9863afca942d0fb89d7c9ac0c99bafc3749504ded97730"
target = "x86_64-pc-windows-msvc"
native-sha256 = "9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08"
ffi-libs = ["user32", "gdi32", "lib/winplot_core.lib"]
files = ["lib.matrix", "spider.toml"]
used_by = ["demo_app"]

spkg verify, spkg audit, and spid3r build verify vendored sources, .spid3r-manifest.toml snapshots, and _native/<target>/ binaries against spider.lock.

Version Constraint Syntax

Constraint Behavior Example Matches
^1.2.3 / ^0.2.1 SemVer caret: compatible within major if > 0, or within minor for 0.x (^0.2.1 matches 0.2.x, excludes 0.3.0) 1.2.3, 1.9.0 (not 2.0.0)
~1.2.3 Tilde range: same major and minor, at least patch 1.2.3, 1.2.9 (not 1.3.0)
>=1.0.0, <2.0.0 Compound AND ranges using >=, <=, >, < 1.0.0, 1.9.4 (not 2.0.0)
=1.2.3 or 1.2.3 Exact major.minor.patch pin (* matches any) 1.2.3 only

05Installing & Managing Dependencies (All 4 Sources)

Install from local paths, pinned Git repositories, local directories, or signed HTTP(S) registries.

Source Type Install Command spider.toml Form Notes
Local Path spkg add util --path ../util util = { path = "../util" } Ideal for monorepos and active local development; re-run spkg install to refresh vendor/.
Git URL spkg add router --git https://example.com/r.git --rev v1.0.0 router = { git = "...", rev = "v1.0.0" } Supports https:// and ssh:// by default; hooks and submodules disabled; pins 40-hex commit in spider.lock.
Local Registry spkg add json_fmt --version "^1.2.0" json_fmt = { version = "^1.2.0" } Resolves against $SPID3R_REGISTRY/<name>/<ver>/ (or named sub-registry directories).
HTTP(S) Registry spkg install nettools or spkg install hello==0.1.0 nettools = { version = "^0.1.2" } Defaults to https://spid3r-spkg.github.io; verifies Ed25519 signatures, checks yanked.txt, prefers target wheels, and caches locally.

06Multi-Package Workspaces

Share one spider.lock and vendor/ directory across cooperating packages.

Workspace Directory Tree

workspace layout
tree 
my_workspace/
├── spider.toml          # [workspace] root manifest
├── spider.lock          # single shared lockfile at workspace root
├── vendor/              # shared vendored dependencies
├── core_lib/
│   ├── spider.toml
│   └── src/lib.matrix
└── cli_app/
    ├── spider.toml      # depends on core_lib = { path = "../core_lib" }
    └── src/main.matrix

Workspace Manifest

my_workspace/spider.toml
toml 
# A workspace root may omit [package] when coordinating members
[workspace]
members = ["core_lib", "cli_app"]

Running spkg install, spkg install --dev --extra gpu, or spkg verify in the root unifies dependency constraints across all listed workspace members automatically.

07Publishing, Tar Packaging & Static Registries

Publish immutable, signed releases or prebuilt binary wheels to any static HTTP(S) host or GitHub Pages repo.

Publishing Pure-Source & Binary Wheels

terminal — publish & build
bash 
# Publish pure-source release into ./registry/<name>/<version>/
spkg publish --to-dir /srv/spid3r-registry

# Publish a prebuilt binary wheel for a specific target triple
spkg publish --to-dir /srv/spid3r-registry --target x86_64-pc-windows-msvc

# Build executable with automatic FFI verification & linking
yamc src/main.matrix -o app.exe --release

Publishes are immutable: source releases and per-target wheels never overwrite prior digests, and each artifact signs both sha256*.txt.sig and manifest*.sha256.sig.

Static Registry File Layout

registry tree
tree 
<registry-root>/
├── registry.toml[.sig]        # descriptor, moved_to migration, mirrors
├── registry.pub               # 64-hex Ed25519 public key
├── catalog.txt[.sig]          # searchable index + categories + targets
└── <pkg-name>/
    ├── index.txt[.sig]        # available versions
    ├── yanked.txt[.sig]       # excluded from latest resolution & flagged by audit
    ├── advisories.txt[.sig]   # security advisories checked by spkg audit
    └── <version>/
        ├── spider.toml
        ├── sha256[-<target>].txt[.sig]
        ├── manifest[-<target>].sha256[.sig]
        └── package[-<target>].tar

Self-Contained Tar Packing

terminal — pack & unpack
bash 
spkg pack -o dist/my_pkg-0.1.0.tar
spkg unpack dist/my_pkg-0.1.0.tar ./extracted_pkg

Minimal vs. TLS Builds

Standard builds with the tls Cargo feature (cargo build --features "native tls") support both http:// and https:// registries. Builds compiled with --no-default-features support local directory registries, --path, --git, and http:// registries and report a clear error if given an https:// URL.

08Security, Ed25519 Signing & spid3r.ini

Pin trusted Ed25519 public keys, rotate keys cleanly, and configure defaults in spid3r.ini.

Ed25519 Registry Signing & Pinning

terminal — publisher signing & consumer pin
bash 
# Publisher: supply 64-hex Ed25519 secret seed (never commit registry.key!)
SPID3R_SIGN_KEY=<64-hex-seed> spkg publish --to-dir /srv/registry

# Consumer: pin trusted 64-hex public keys (fail-closed on missing/bad sigs)
SPID3R_TRUST_PK=<64-hex-pubkey> spkg install nettools

When packages.trust_pk / SPID3R_TRUST_PK is configured, every metadata file (registry.toml.sig, catalog.txt.sig, index.txt.sig, yanked.txt.sig, advisories.txt.sig), archive digest (sha256*.txt.sig), and manifest snapshot (manifest*.sha256.sig) is verified before extraction.

Hardening Guarantees

  • Zero install hooks: spkg add, install, and tool install execute zero package install scripts.
  • Archive & filesystem safety: Ustar extraction rejects PAX extended headers, symlinks, Windows reserved device names, path traversal, and normalized case collisions, capped at 10,000 entries / 128 MiB.
  • Strict --frozen & HTTPS mirrors: Hashes, target triples, and FFI libraries are verified before touching vendor/; HTTPS registries reject plain HTTP mirror downgrades; Bearer tokens stay bound to the initial HTTPS origin.
  • Pre-link native FFI verification: yamc / spid3r build re-check .spid3r-manifest.toml and locked ffi-libs before linking [ffi] binaries; spkg tool install blocks [ffi] tools cleanly.

spid3r.ini Keys & Environment Overrides

spid3r.ini Key Environment Variable Default Purpose
packages.registry SPID3R_REGISTRY https://spid3r-spkg.github.io Default registry URL/directory or comma-separated mirror list (set none to disable).
packages.trust_pk SPID3R_TRUST_PK Unset One or more comma-separated 64-hex Ed25519 public keys (supports zero-downtime key rotation).
packages.allow_insecure_git SPID3R_ALLOW_INSECURE_GIT false Allow unencrypted http:// Git dependency URLs (keep false in production).
packages.allow_local_git SPID3R_ALLOW_LOCAL_GIT_DEPS false Allow local filesystem paths as git = "..." URLs (prefer path = "...").
paths.state_dir SPID3R_STATE_DIR OS state dir Base directory containing tools/ and bin/ shims; reset to default via spid3r control config reset paths.state_dir.
N/A (auth env) SPID3R_REGISTRY_TOKEN Unset Optional Bearer token sent only over https:// to the initial registry origin.
N/A (publisher env) SPID3R_SIGN_KEY Unset 64-hex Ed25519 secret seed used by spkg publish --to-dir (or pass --sign-key).

10Troubleshooting & FAQ

Fast answers to common setup, import, FFI, and spkg tool PATH issues.

I ran spkg tool install <pkg> — why is the command not found in my shell?

Two common reasons: (1) open a new terminal if you just ran the Spid3r installer so it reloads PATH (%LOCALAPPDATA%\Spid3r\state\bin on Windows, ${XDG_STATE_HOME:-$HOME/.local/state}/spid3r/bin on Linux/macOS); or (2) paths.state_dir in spid3r.ini or SPID3R_STATE_DIR points elsewhere — check the note printed by spkg tool install and run spid3r control config reset paths.state_dir to restore the default.

Why does import "my_pkg/lib" say module not found?

Run spkg install so dependencies are unpacked into vendor/my_pkg/, and omit src/ from the import path (files in my_pkg/src/ map directly to vendor/my_pkg/). Inspect search resolution with spkg modules src/main.matrix --tree.

Why did spkg verify fail after editing a file in vendor/?

vendor/ is hash-locked against spider.lock. Edit the original package source (or update the version), then run spkg install to re-vendor cleanly.

Should I commit spider.lock and vendor/ to Git?

Always commit spider.toml and spider.lock, and gate CI with spkg install --frozen && spkg verify && spkg audit. Commit vendor/ too if you need 100% air-gapped builds without touching remotes during CI.

How do native C/C++/Rust FFI wheels and auto-linking work?

Place platform libraries in native/<target>/, declare [ffi] libs / bundled / runtime_libs in spider.toml, and publish with spkg publish --to-dir <dir> --target <triple>. Consumers run spid3r build / yamc with zero extra flags; Spid3r verifies hashes against spider.lock and copies runtime_libs next to the output binary (disable with --no-auto-ffi).

How do I reset an overridden paths.state_dir in PowerShell on Windows?

Use spid3r control config reset paths.state_dir instead of passing an empty "" argument (Windows PowerShell 5.1 strips empty string arguments before spawning native executables).
